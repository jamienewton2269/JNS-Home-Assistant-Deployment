# Home Assistant dashboard graph standard

Confirmed by Jamie on 6 November 2026: reuse [Statistics Graph Chart Card](https://github.com/cataseven/Statistics-Graph-Chart-Card) for dashboard graphs throughout Home Assistant. Install and update this single shared frontend dependency through HACS on each Home Assistant instance serving these dashboards.

Use `custom:statistics-graph-chart-card` for new graphs and migrate existing graph cards while preserving their data meaning. Use direct sensor bindings where sufficient. Keep consistent sensor colours, readable legends and appropriate time ranges. Preserve missing-data gaps. Use suitable resolution and existing Home Assistant statistics for long views; avoid unnecessary background polling and animation on phones/tablets.

Preserve existing entity IDs, attributes, units, counter aggregation, thresholds, signed power direction, time range and state timelines during conversion. Temperature, humidity, power and energy must retain their correct units and aggregation. Do not invert the grid sensor or alter the corrected Energy import/export configuration as part of graph styling.

Inventory registered YAML and storage dashboards, back up each changed configuration, validate conversion and verify rendering before marking migration complete. Keep private dashboard content and health readings out of public GitHub logs. Stock Home Assistant Energy and History panels are generated by Home Assistant; using this card in editable dashboards does not replace those built-in panels globally.

Adoption of this standard does not indicate that live installation or migration has completed; track actual deployment and verification separately.
